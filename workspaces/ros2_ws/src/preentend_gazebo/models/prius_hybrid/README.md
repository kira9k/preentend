# Prius visual model

Source: [osrf/gazebo_models/prius_hybrid](https://github.com/osrf/gazebo_models/tree/master/prius_hybrid).

Included files: `meshes/Hybrid.obj`, `meshes/Hybrid.mtl`, and the three PNG textures in `materials/textures/`. The mesh is used as one visual so that the body, interior, windows and wheels stay in their original positions. The `Windows` material in `Hybrid.mtl` was changed to an opaque dark color for this scene.
